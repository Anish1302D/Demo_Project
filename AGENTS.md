# Teamboard Demo Project

## Overview

This workspace contains a lightweight demo app with a static frontend, a Python backend, and a tiny assistant module.

## Conventions

- Keep the demo dependency-light and easy to run locally.
- Prefer standard library code unless a library is clearly necessary.
- Keep edits small and focused on the requested demo behavior.

## Run Notes

- Start the backend with `python backend/server.py` from the `teamboard` folder.
- Open `frontend/index.html` in a browser after the backend is running.
